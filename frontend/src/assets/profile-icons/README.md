# Author profile icons

ORCID, GitHub, Google Scholar, LinkedIn, and X SVGs are from Simple Icons 11.15.0:
https://github.com/simple-icons/simple-icons/tree/11.15.0/icons

Simple Icons is distributed under CC0; see LICENSE.simple-icons.md. Brand marks remain the property of their respective owners.

SVG fills use the brand colours: ORCID green, Google Scholar blue, LinkedIn blue, and GitHub/X black.
OpenReview uses the Material Symbols rate_review icon in red.
Icons are faded at rest and reach full opacity on individual link hover or keyboard focus.
Assets are bundled locally; displaying profiles does not contact these services.
